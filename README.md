# 함께, 가을

교육정보화본부 워크숍 일정·날씨·이동 지도 웹서비스. 첨부 일정표를 2026년 10월 29~30일로 적용했습니다.

`python -m http.server 8080 --bind 127.0.0.1 --directory public`로 실행한 뒤 http://localhost:8080 에 접속합니다. 별도의 빌드나 API 키가 필요하지 않습니다.

- 일정: 1·2일차 탭, 전체 방문지 지도 연결, 현재 날짜 탭 인쇄
- Day 01: 수정 일정표의 13개 일정(11:30 솔향기 집결 → 점심 → 은하수교 → 철원역사문화공원·소이산 → 카페 보이드(CAFE VOID) → 숙소 체크인 → 만찬 → 여가·휴식)을 반영했습니다. 16:30~16:35 이동은 배정 5분과 표의 예상 10~12분이 달라 현장 확인이 필요합니다.
- Day 02: 08:00 아침 식사 → 체크아웃 → 10:00 플로깅 → 단체 사진 → 오찬 이동 → 산비탈손두부 → 가비가배 → 14:00 서울 방향 복귀의 8개 일정입니다. 전화번호·주소·예상 이동 시간은 제공 일정표 기준입니다.
- 날씨: Open-Meteo 16일 예보에서 행사 날짜를 정확히 선택. 예보 미제공·통신 실패는 별도 표시하며 예시 수치를 사용하지 않습니다.
- 지도: Google 지도 임베드와 큰 지도 열기, 네이버 장소 검색을 함께 제공합니다. 두 서비스의 자동차 길찾기를 사용할 수 있습니다. Google은 선택한 출발지·도착지를 자동으로 전달하며, 네이버는 각각 복사한 뒤 길찾기에 입력합니다. 검색 기반 장소이므로 예약 지점을 반드시 확인하세요.
- 네이버 지도 웹사이트는 외부 iframe 표시를 차단하므로 새 탭에서 열립니다. 페이지 내 지도가 필요하면 네이버 Maps Dynamic Map 애플리케이션의 Client ID와 서비스 URL 등록이 필요합니다.
- 숙소: 한화리조트 산정호수 안시. 첫째 날 카페는 카페 보이드(CAFE VOID), 둘째 날 카페는 가비가배로 일정 및 지도·길찾기에 반영됩니다.
- 장소·준비물은 브라우저 localStorage에 저장됩니다. 다른 기기와 동기화되지 않습니다.
- 출발지의 ‘현재 위치’를 선택하면 브라우저 위치 권한을 요청합니다. 확인된 좌표는 구글 길찾기 출발지에 반영되며, 저장하지 않고 현재 페이지에서만 사용합니다. 네이버 길찾기는 네이버 화면의 ‘현재 위치’를 선택합니다. 거부·시간 초과 시 재시도하거나 다른 출발지를 선택할 수 있습니다.
